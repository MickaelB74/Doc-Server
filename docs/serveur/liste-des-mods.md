# Liste des mods

Le dossier des mods du serveur contient **63 fichiers**, mais tous ne sont pas des mods « de jeu ». Cette page les trie : **42 mods** font réellement tourner le serveur, **15 bibliothèques** ne servent qu'à faire fonctionner d'autres mods, et **6 mods** ne servent qu'à l'affichage côté joueur.
{ .chapeau }

!!! info "Relevé du 27 octobre 2026"

    Liste établie à partir des fichiers présents sur le serveur (Youer 1.21.1, base NeoForge 21.1.219) et de leurs dépendances déclarées. Elle sera à mettre à jour à chaque ajout ou retrait de mod.

| Catégorie | Nombre | Rôle |
|---|---|---|
| [Mods de contenu](#mods-de-contenu) | 37 | Ce que vous voyez en jeu : créatures, objets, blocs, structures, mécaniques |
| [Mods techniques du serveur](#mods-techniques-du-serveur) | 5 | Réglages de génération du monde et mods maison, invisibles pour le joueur |
| [Mods côté client](#mods-cote-client) | 6 | Affichage et performances : sans effet sur le serveur |
| [Bibliothèques](#bibliotheques) | 15 | Code partagé dont d'autres mods ont besoin |

La colonne **Chez le joueur** indique s'il faut aussi installer le mod dans votre jeu :

- **Oui** : le mod ajoute des blocs, objets ou créatures, il doit être présent chez vous ;
- **Non** : le mod n'agit que sur le serveur ;
- **Facultatif** : à votre convenance.

Inutile de les installer un par un : le [modpack](modpack.md) le fait pour vous.
