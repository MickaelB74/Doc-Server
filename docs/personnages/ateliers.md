# Aide-mémoire des ateliers

Ce que demande l'atelier de chaque artisan, en un seul tableau. Sauf mention contraire, chaque atelier demande aussi les **exigences communes** : 1 porte, un toit sur 60 % du sol et 2 sources de lumière. Chaque bloc bonus présent rapporte **+5 points**.
{ .chapeau }

!!! tip "Le nom proposé"

    À la création d'un atelier, le jeu propose un nom (ci-dessous). Vous pouvez le reprendre d'un clic ou en choisir un autre : un seul mot, 24 caractères au plus.

!!! info "L'annexe de travail"

    L'annexe où travaillent les employés d'un artisan exige les **deux premiers blocs** de sa colonne « Bonus du métier » (dans l'ordre du tableau ; les blocs d'un mod absent sont ignorés), les suivants rapportant des points, ainsi qu'**une source de lumière**, sans porte ni toit. Voir [Le travail des habitants](../guide/habitants.md#le-travail-des-habitants).

## Les blocs acceptés

| Bloc demandé | Variantes qui comptent |
|---|---|
| **Bûches** | Chêne, sapin, bouleau, acajou, acacia, chêne noir, palétuvier ou cerisier (ni bois écorcé, ni tiges du Nether) |
| **Briques de pierre** | Normales, moussues, craquelées ou sculptées |
| **Verre** | Blocs, verre fumé, vitres, verres et vitres teintés |
| **Laine** | Toutes les couleurs |
| **Enclume** | Intacte, ébréchée ou endommagée |
| **Chaudron** | Vide ou rempli (eau, lave, neige poudreuse) |
| **Feu de camp** | Normal ou des âmes |
| **Barrières** | Toutes les barrières (bois, briques du Nether) |
| **Planches** | Toutes les essences (pour Ragnar, uniquement l'épicéa) |
| **Bambou** | Bloc de bambou, bloc de bambou écorcé, planches de bambou, mosaïque de bambou |
| **Bannière, bougie, lit, pot de fleurs** | Toutes les couleurs et variantes |

!!! info "Les personnages liés à un mod"

    Robinson Crusoé, le capitaine Achab, Jack Sparrow, Obélix, Miyamoto Musashi, Gambrinus, Geppetto, Ragnar, Jeanne d'Arc, Harold et Hercule s'installent normalement même si leur mod est absent du serveur, mais n'ouvrent alors pas de commerce (voir [Mods et plugins](../serveur/mods-et-plugins.md#les-mods-de-contenu)). Gandalf fonctionne avec ou sans Iron's Spells 'n Spellbooks : seuls ses blocs bonus changent.
